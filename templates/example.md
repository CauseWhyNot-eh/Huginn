# Example: concept visualiser v0.1

## Raw

An app/website to visualise any scientific or mathematical concept. 2026-09-10.

## Gaps closed

- User: highschool plus college.
- Scope: physics electrics, maths integration plus differentiation, chemistry organic.
- Mode: autogen website first.

## Picked direction

Type a concept, get a playable visual plus plain explainer.

## Features

### V1

- Search box for concept.
- Auto visual with sliders.
- Plain explainer next to visual.
- Share link.

### Later

- Saved library of 20 hand-checked visuals.
- 3D views.
- Accounts plus teacher sets.

## Build steps

1. One web page with search plus viewer.
2. Concept router: electrics vs calculus vs organic.
3. Visual renderer with sliders.
4. Explainer writer.
5. Share link save.

## Working

User flow: type concept -> play visual -> move sliders -> read steps.
System flow: text in -> router picks template -> code draws visual -> explainer fills values.
